# ぽよまるメーカー

GIGAスクール構想を題材にした、小中学生向けの学習ポイント・キャラクター制作プロトタイプです。HTML・JavaScript・SVGのみで動作し、ログイン・バックエンド・DBは不要です。

## 起動・GitHub Pages

GitHub Pagesでは Settings → Pages → Build and deployment → Deploy from a branch で公開ブランチと /(root) を選びます。入口は https://okinopita.github.io/poyomarumaker/poyomaru/ です。ビルドは不要です。公開設定はリポジトリ管理者が行ってください。

ローカルではリポジトリ直下で静的HTTPサーバーを起動し、/poyomaru/index.html を開きます（Pythonがあれば `python -m http.server 8000`）。ブラウザによって file:// ではCanvasによる画像処理・保存が制限されるため、GitHub PagesまたはHTTPでの利用を推奨します。

## 操作

1. 動画視聴回数 × 10pt、テスト点数 × 0.5ptを受け取ります。100ptで抽選1回。素体・パーツを重複ありで抽選し、結果を中央に表示します。
2. カテゴリ内の所持アイテムを押すとパーツを1個追加します。同じパーツを何個でも配置できます。素体を選ぶと、1体だけ切り替えます。
3. 「配置したパーツ」一覧かプレビュー上のパーツを押して選択します。透明部分を除いて、前面に見えているパーツを選びます。隠れたパーツは一覧から選択できます。
4. 選択したパーツをドラッグ、または横位置・縦位置のスライダーで移動できます。大きさ・回転も個別に調整できます。タッチ操作に対応しています。
5. 「複製」で選択中パーツを少しずらして追加。「削除」はその1個だけを取り除きます。素体は複製・削除できません。
6. 「最前面へ」「最背面へ」で素体をまたいで重なり順を変更できます。一覧は前面から順に表示します。
7. リセットは選択した1個の位置・大きさ・回転を初期値へ戻します。重なり順は維持します。「初期状態に戻す」は素体と全パーツの配置を戻し、ポイント・所持品・作品名は残します。
8. 作品名を入力し、「作品を保存」で背景透過PNGをダウンロードします。表示中の全パーツ・重なり順・変形を反映し、選択枠やUIは含めません。作品名をファイル名に使います。

プレビューはSVGの不透明領域を計測し、全体が収まるように自動調整します。ドラッグ中は倍率を固定し、指を離すと再調整します。移動範囲は共通400×400座標系で各軸±400、大きさは20〜300%です。PNGは全体に24座標分の余白を付け、最大辺2400pxの範囲で2倍解像度にします。

## 外部掲示板の設定

editor.js 先頭の `const BOARD_URL = '';` にPadlet等の公開URLを設定します。空文字なら「準備中」と案内し、編集・画像保存は通常どおり使えます。HTTP/HTTPSだけを開きます。設定後は「みんなの作品を見る・投稿する」で別タブが開きます。

「作品を保存」→ 掲示板を開く → 利用者が画像・作品名・任意のニックネームを投稿する流れです。自動投稿・画像の外部送信・独自掲示板は実装していません。

## 保存形式とパーツ追加

- ポイント・所持数・素体・作品名・全インスタンスを localStorage の poyomarumaker-v3 に保存します。ブラウザや配信元が異なると保存領域も異なります。
- poyomarumaker-v2、giga-chimera-miniproto-v1 の旧データを探し、equipped / カテゴリ別 transform を1個ずつのインスタンスへ移行します。旧キーは残します。全パーツ削除済みの状態も保持します。
- 各インスタンスは id（一意）、itemId（元アイテム）、x、y、scale、rotate、z を持ちます。素体は bodyId で別管理し、描画順の基準は z=0 です。
- アイテム定義は app.js、編集・保存・描画処理は editor.js。新しい独立パーツは PARTS に登録し、400×400座標系のSVGを assets/ に置くと、追加・複製・変形・抽選の対象になります。左右セットに依存する処理はありません。
- 全SVGは既存ファイルのままです。素体の輪郭を仮定するマスクは使いません。既存の両目SVGを片目へ分割する処理はなく、複製時も元SVG全体を複製します。
- 開発用の全アイテム解放ボタンを維持。実際の動画視聴や成績認証とは接続していません。

## ブラウザテスト

Node.js 22以上とChromium系ブラウザを使い、リポジトリ直下で `node tests/browser.test.mjs` を実行します。追加のnpmパッケージは不要です。必要に応じて CHROME_BIN にブラウザ実行ファイルを指定してください。

初期表示、独立した複製・変形・削除、前後順、マウス・タッチ、再読み込み、旧データ移行、ポイント・重複抽選、透過PNGと実ダウンロード、掲示板URL設定時・未設定時を確認します。テスト用プロファイルを使うため、普段のブラウザデータは変更しません。
