# ぽよまるメーカー

GIGAスクール構想をテーマにした、学習ポイントとキャラクターカスタマイズのプレゼン用プロトタイプです。

## 起動

`index.html` をChromeなどのブラウザで開いてください。サーバーやログインは不要です。`index.html`、`app.js`、`assets/` を同じフォルダ構成に配置します。

GitHub Pagesに公開する場合も静的ファイルだけで動作します。

## 使い方

1. 学習動画の視聴回数（1回10pt）・テストの点数（1点0.5pt）を入力し、ポイントを受け取る。
2. 100ptでガチャを回して、パーツまたは素体を獲得する。重複あり・救済なし。獲得時は中央にアイテムだけを表示する演出が出る。
3. エディターで「素体」「耳・頭」「目」「口」「手足」「しっぽ」を選び、所持アイテムを装着する。
4. 部位を選択した状態でキャラクター上をドラッグすると位置を動かせる。「大きさ」「回転」も調整可能。素体の輪郭自体は固定。
5. デモ確認用に「開発用：全アイテムを解放」を用意。ポイント、所持品、装着状態、編集位置は `localStorage` に保存される。

## グラフィック

- 元のぽよまる `assets/base.svg`、初期5パーツSVGは改変していません。
- 素体バリエーションは、輪郭を維持したまま色・模様を変更した `base_devil.svg`, `base_dragon.svg`, `base_professor.svg`, `base_alien.svg`。
- 各素体に対応する5部位のSVG（全20種類）を追加。パーツは他の素体とも自由に組み合わせられます。
- 全SVGは `400×400 / viewBox 0 0 400 400` で共通の座標を使用しています。
- 以前の強調しすぎたパーツ（巨大な口など）は旧ファイルとして残していますが、現在のガチャには含めていません。

## 仕様・制約

- 実際の学習システムとは接続せず、入力値はデモ用の自己申告です。
- アカウント、共有交換、掲示板、サーバー通信はありません。
- 編集は部位単位です（両目を別々に動かす機能は未対応）。
- 同じ端末・同じブラウザの保存状態を利用します。ブラウザによっては `file://` での保存に制限があるため、その場合はGitHub Pages等で開いてください。
